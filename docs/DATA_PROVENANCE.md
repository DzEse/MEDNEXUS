# Data Provenance

## Default implementation
All default MEDNEXUS enterprise tables are **synthetic datasets** generated by `mednexus/synthetic.py` using a fixed random seed and documented cross-domain relationships.

## Public-source extension candidates
- UCI AI4I 2020 Predictive Maintenance Dataset — source for independent model benchmarking; do not call it MEDNEXUS proprietary data.
- UCI SECOM — source for independent semiconductor-process quality exploration.
- NASA Prognostics Data Repository / C-MAPSS — source for independent prognostics work when download availability and usage conditions are verified at implementation time.

Public datasets must retain original attribution, source URLs, license/usage notes, grain, fields, limitations and intended analytical use.
