# Scenario Methodology

## Purpose
Compare management interventions without pretending that observational associations are causal estimates.

## Structure
**Baseline → assumption → expected directional change → simulated result → difference.**

## Parameters in the default build
- downtime reduction %
- defect reduction %
- workforce-capacity improvement %

## Outputs
- simulated downtime
- simulated defects
- simulated capacity gap
- simulated good units
- simulated opportunity value

Every scenario result is **simulated**. The default response functions are transparent sensitivity assumptions and should be recalibrated from real intervention evidence before operational use.
